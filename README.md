## 📌 Sobre o Projeto

Este projeto foi desenvolvido como um trabalho freelance para a **Alibi**, uma loja de vestuário. O principal objetivo foi criar uma interface web moderna, atraente e totalmente responsiva, funcionando como uma vitrine digital para destacar os produtos da marca e proporcionar uma excelente experiência aos clientes.

## 🎯 Funcionalidades

* **Vitrine de Produtos:** Apresentação clara, organizada e elegante das peças de vestuário.
* **Design Responsivo:** Layout fluido que se adapta perfeitamente a qualquer tamanho de ecrã (computadores, tablets e telemóveis).
* **Interface Dinâmica:** Interações fluídas e manipulação do DOM desenvolvidas com JavaScript para elevar a experiência do utilizador.
* **Navegação Intuitiva:** Estrutura visual planeada com foco na usabilidade e na retenção do cliente.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as bases fundamentais do desenvolvimento front-end, sem dependência de frameworks externos pesados:

* **HTML5:** Estruturação semântica e acessibilidade.
* **CSS3:** Estilização visual, animações e criação de layouts responsivos (Flexbox/Grid).
* **JavaScript (Vanilla):** Lógica de interface e interatividade.

## 💻 Como executar o projeto localmente

Como o projeto é composto exclusivamente por ficheiros estáticos no front-end, executá-lo localmente é um processo simples. Siga os passos abaixo:

**1. Faça o clone do repositório:**
Abra o seu terminal e execute o seguinte comando:
`git clone https://github.com/Lucas-S-Cavalheiro/Loja-Alibi.git`

**2. Aceda ao diretório do projeto:**
Abra a pasta clonada no seu editor de código (como o VS Code, por exemplo).

**3. Abra no navegador:**
Basta dar um duplo clique no ficheiro `index.html` para que o site seja aberto no seu navegador web padrão. Se estiver a utilizar o VS Code, pode utilizar a extensão *Live Server* para executar o projeto com recarregamento automático.
